## 1. 现状：没有 locale 路由 ⏸

**必须诚实说明**：本项目的"双语"指**同一页面内的 CJK + Latin 混排排版**，**不是**多语言站点路由。

| 维度       | 现状                                                                         |
| ---------- | ---------------------------------------------------------------------------- |
| 路由       | **无 `/zh/`、`/en/` 等 locale 前缀**；全部内容单一 URL 空间                  |
| 语言字段   | frontmatter **没有** `lang` / `locale` 字段（见 `docs/CONTENT_GUIDE.md` §3） |
| 语言切换器 | 无                                                                           |
| `hreflang` | 未实现（无多语言内容版本）⏸                                                  |
| 单篇语言   | 一篇文章即一种语言为主，技术术语保留英文                                     |
| 站点主语言 | `zh`（`<html lang="zh">` ⏸ 待确认实际取值）                                  |

因此，"中英双语同权"是**排版原则**（`docs/VISUAL_DESIGN_SPEC.md` 原则 5），而非路由架构。任何多语言版本的组织方式都属于未来计划（见 §7）。

## 2. 排版度量

以下为长文底线，直接取自 `docs/VISUAL_DESIGN_SPEC.md` §3：

| 度量     | 取值                                 | 理由                                      |
| -------- | ------------------------------------ | ----------------------------------------- |
| 正文行高 | **1.75**                             | CJK 字形方正，需要比拉丁更大的行距        |
| 正文行长 | **`max-width: 42rem`**               | ≈70+ 拉丁字符 / ≈36 个 CJK 字符           |
| 正文字号 | ≥16px（`body` = 16px）               | 护眼底线                                  |
| 对齐     | 全部**左对齐**，禁止两端对齐         | 两端对齐在 CJK/拉丁混排下会产生难看的空隙 |
| 数字     | `font-variant-numeric: tabular-nums` | 日期、阅读时长等列对齐                    |

**字阶（16px 基准，1.25 模数）**：

| 角色      | 尺寸 | 行高     | 字重 | 用途                        |
| --------- | ---- | -------- | ---- | --------------------------- |
| caption   | 13px | 1.5      | 400  | 图注、辅助说明              |
| meta      | 14px | 1.5      | 400  | 日期、标签、阅读时长        |
| body      | 16px | **1.75** | 400  | 正文（CJK 需要更大行高）    |
| lead / h4 | 20px | 1.6      | 400  | 摘要、导语                  |
| h3        | 25px | 1.35     | 600  |                             |
| h2        | 31px | 1.3      | 600  | 页面 h1（列表页）           |
| h1        | 39px | 1.25     | 700  | 文章标题（移动端降为 31px） |

## 3. 中英混排规则

### 3.1 字体栈

| 角色      | 字体栈                                                                                            | 说明                                                                   |
| --------- | ------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| 标题/展示 | `"Source Serif 4", "Source Han Serif SC", "Noto Serif SC", "Songti SC", "SimSun", serif`          | Latin 自托管 woff2 子集；中文依赖本地宋体族（**不加载 CJK 网络字体**） |
| 正文/UI   | `system-ui, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif` | 长文可读性优先，中英同栈                                               |
| 代码      | `ui-monospace, "SF Mono", "JetBrains Mono", "Cascadia Mono", Consolas, monospace`                 | 代码块、行内码、日期数字                                               |

- Latin 子集预算 ≤60KB，`font-display: swap`，仅预加载文章页 h1 字重（700）。
- CJK **不加载网络字体**：字库体积违反 BundleSizeBudget，靠系统字体栈兜底。

### 3.2 标点

| 规则            | 说明                                                                                    |
| --------------- | --------------------------------------------------------------------------------------- |
| 全角 / 半角     | CJK 语境用全角标点（`，。：；""（）`）；拉丁/代码/URL 上下文用半角（`,. :;""()`）       |
| 代码内标点      | 一律半角，不因周围是中文而全角化                                                        |
| 标点挤压        | CJK 行首/行尾标点挤压（punctuation compression）——验收项见视觉规范 §12 ⏸ 待确认具体 CSS |
| 省略号 / 破折号 | 中文用 `……` / `——`；英文用 `...` / `—`，不混用                                          |
| 括号            | 中文括注用全角 `（）`；纯英文/代码用半角 `()`；混排时按**主语境**选择                   |

### 3.3 中英间隙与断行

| 规则       | 说明                                                                                                                                    |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 中西文间隙 | CJK 与 Latin/数字之间宜有约 1/4 em 间隙——靠排版引擎或手工空格 ⏸ 待确认实现方式（`text-autospace` / `text-spacing-trim` 浏览器支持不一） |
| 断行       | 允许在 CJK 字符间断行；拉丁单词整体不拆（`overflow-wrap` 兜底长 URL/代码）                                                              |
| 禁止孤字   | 标点不落行首（`line-break: strict` 方向）⏸ 待确认具体取值                                                                               |
| 数字与单位 | 数字用拉丁字体渲染；中文量词紧随数字，不加空格                                                                                          |
| 禁止的做法 | 不在标题中给单个词染色/斜体（`docs/VISUAL_DESIGN_SPEC.md` §3.3）                                                                        |

> ⏸ 上表中标注"待确认"的 CSS 行为需在 `src/styles/*.css` ⏸ 重写后实测浏览器支持，不凭空断言。

## 4. 数字、日期与本地化

| 项            | 约定                                                                     |
| ------------- | ------------------------------------------------------------------------ |
| 数字字形      | 日期、阅读时长用 `tabular-nums`（等宽数字）                              |
| 日期格式      | UI 显示 `YYYY-MM-DD`（ISO），如 `2026-10-02`；frontmatter 用 YAML 日期   |
| 时长          | "约 8 分钟"（CJK 语境）                                                  |
| 分组 / 格式化 | 优先浏览器原生 `Intl.*`（遵循 NativeApiFirst），不引入日期库做展示格式化 |
| 时区          | 构建时区未固定 ⏸ 待确认（可能影响 `publishDate` 显示）                   |

## 5. 双语内容的组织

当前**没有** per-locale 字段，可选做法（均为内容约定，非架构）：

| 模式             | 做法                                    | 适用                      |
| ---------------- | --------------------------------------- | ------------------------- |
| 单篇混排（默认） | 正文以中文为主，术语/引用保留英文       | 技术长文                  |
| 双篇独立         | 中英各写一篇，用共同 tag 或命名关联     | 需要独立英文版时 ⏸ 待确认 |
| 标题双语         | `title` 内混排，如 `Astro 7 迁移踩坑记` | 常见                      |

> 由于无 locale 路由与 `lang` 字段，浏览器/SEO 无法区分语言版本；真正的多语言支持属于 §7 未来计划。

---

## 6. 无障碍与护眼相关性

- 行高 1.75、行长 ≤42rem、字号 ≥16px 同时是护眼与可读性要求（`docs/VISUAL_DESIGN_SPEC.md` §8）。
- 对比度、焦点轮廓、缩放见 `docs/ACCESSIBILITY.md`。
- 200% 缩放不得产生横向滚动（正文与代码块自身滚动除外）。

## 7. 未来计划草图（尚未实施）⏸

以下仅为方向草图，**未落地、无对应代码**：

1. **locale 路由**：引入 `/zh/`（默认）与 `/en/`，或使用 Astro 内置 `i18n` 配置。
2. **语言字段**：frontmatter 增加 `lang` / `translationKey`（或 Content Collections 的 `translationOf`）。
3. **语言切换器**：`Navbar.End` 增加切换入口，记忆用户偏好。
4. **`hreflang`**：为每个语言版本输出 `<link rel="alternate" hreflang="...">`。
5. **多语言 RSS**：按 locale 拆分 feed（见 `docs/SEO.md`）。
6. **CJK 字体策略复核**：若必须统一字体，先走 `docs/adr/0010-dependency-evaluation.md` 评估再议。

> 任何上述变更属于架构级改动，需先创建 ADR 并更新 `CONTEXT.md`（参见知识库维护流程）。

## 8. 检查清单

- [ ] 正文行高 1.75、行长 ≤42rem、左对齐（无两端对齐）
- [ ] 日期/时长使用等宽数字
- [ ] CJK 用全角标点、代码/URL 用半角，不混用
- [ ] 长 URL / 代码不撑破 42rem 列宽
- [ ] `<html lang>` 与实际主语言一致（⏸ 待确认取值）
- [ ] 无 CJK 网络字体加载；Latin 子集 ≤60KB
- [ ] 混排样张在亮/暗双主题下目视检查（标点、间隙、断行）
