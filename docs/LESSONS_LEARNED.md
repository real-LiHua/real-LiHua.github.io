## 高频坑点

### daisyUI 5

| 坑点             | 现象                    | 根因                                     | 解决                                 | 频次 |
| ---------------- | ----------------------- | ---------------------------------------- | ------------------------------------ | ---- |
| Navbar 类名变更  | `navbar-start` 等类失效 | 升级文档滞后/变更                        | 查阅源码确认新类名，CSS 变量名也变了 | 3    |
| Theme 变量未生效 | 主题切换后样式不变      | `@plugin "daisyui/theme"` 引用变量名错误 | 检查变量名与 `theme-tokens.css` 一致 | 2    |

### Astro View Transitions

| 坑点                 | 现象                              | 根因                                   | 解决                                                      | 频次 |
| -------------------- | --------------------------------- | -------------------------------------- | --------------------------------------------------------- | ---- |
| 主题切换闪白         | 页面切换时短暂闪烁白屏            | `astro:after-swap` 未恢复 `data-theme` | 在 `theme-toggle.ts` 监听 `astro:after-swap` 重新应用主题 | 2    |
| 客户端脚本重复初始化 | View Transitions 切换后脚本跑两次 | 无 `astro:page-load` 守卫              | 使用 `client-runtime` 统一注册，`once: true`              | 1    |

### Astro Content Collections

| 坑点                   | 现象                         | 根因                 | 解决                              | 频次 |
| ---------------------- | ---------------------------- | -------------------- | --------------------------------- | ---- |
| `retainBody: true` OOM | 大量 MDX 文件构建内存溢出    | 完整 body 保留在内存 | 设为 `false`，仅需 frontmatter 时 | 1    |
| Zod 4 语法报错         | `z.coerce.date()` 等语法变更 | 升级未同步文档       | 对照 Zod 4 迁移指南修正           | 1    |

## 可复用模式

### 组件设计

| 模式                      | 描述                                                                 | 适用场景                     | 示例                                                         |
| ------------------------- | -------------------------------------------------------------------- | ---------------------------- | ------------------------------------------------------------ |
| **复合组件 + Slots**      | 父组件暴露 `Start/Center/End/MobileMenu` 子组件，通过 slots 组合     | 导航栏、工具栏、卡片头部     | `Navbar`、`PostCard`                                         |
| **ClientModule 依赖声明** | `dependsOn: ['theme-toggle']` + 拓扑排序自动决定初始化顺序           | 所有需顺序初始化的客户端脚本 | `theme-toggle` → `toc` → `telegram-auth`                     |
| **CSS 变量单一源头**      | `theme-tokens.css` 定义所有语义变量，daisyUI/Tailwind/Prose 直接引用 | 主题系统、设计系统           | `--color-primary` → daisyUI `@plugin` → Prose `--tw-prose-*` |

### 构建管线

| 模式                             | 描述                                                | 适用场景                        | 示例                                      |
| -------------------------------- | --------------------------------------------------- | ------------------------------- | ----------------------------------------- |
| **阶段化管线 + FileWalker 复用** | `BuildPipeline` 注册 5 个阶段，共享 HTML 文件遍历器 | 任何需遍历 `dist/` 的构建后处理 | Pagefind、lychee、vnu、Mermaid、Watermark |
| **错误聚合不中断**               | 每阶段 `try/catch`，超时 60s，最后汇总报告          | 非关键阶段失败不应阻断整体      | Link check 失败不阻断水印注入             |

### 依赖管理

| 模式                | 描述                                                         | 适用场景                       |
| ------------------- | ------------------------------------------------------------ | ------------------------------ |
| **L1 必要性决策树** | 原生 API → 现有依赖 → 轻量实现 → 最后引入新依赖              | 所有新功能选型                 |
| **原生 API 优先**   | `crypto.subtle`、`Intl`、`IntersectionObserver` 等浏览器内置 | 加密、国际化、懒加载、滚动检测 |
| **三层评估文档化**  | PR 必填 L1/L2/L3 评估表，架构级依赖创建 ADR                  | 任何新增/更新依赖              |

## 反模式

| 反模式            | 正确做法                                              | 典型场景                                      |
| ----------------- | ----------------------------------------------------- | --------------------------------------------- |
| 布尔属性爆炸      | 复合组件 + slots                                      | `Navbar` 接受 5+ 个 boolean                   |
| 主题变量重复定义  | 仅 `theme-tokens.css` 定义，`global.css` 仅 `@import` | `global.css` 和 `theme-tokens.css` 都定义颜色 |
| 硬编码等待/延时   | 显式等待、事件监听、`astro:page-load`                 | Playwright 测试、View Transitions 切换        |
| 事后补写模糊注释  | 实时 `@learning:pitfall` 记录现象/根因/解决           | 调试 2 小时后才记录                           |
| L1/L2 堆积不做 L3 | 月度必须归纳沉淀，高频标签 → ADR/文档                 | 学习目录只增不减                              |
