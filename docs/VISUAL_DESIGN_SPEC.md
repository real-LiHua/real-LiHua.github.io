## 1. 设计方向：墨与朱 (Ink & Vermilion)

### 1.1 主体依据

本站是李华的个人技术博客：中英双语长文、代码块、图表、受 Telegram 保护的文章。视觉方向从主体中来：

- **墨**——正文与代码的世界：石墨灰的字、冷白的纸，安静、耐读，衬得住长篇技术文章。
- **朱**——唯一的强调色，取自传统**朱批**（红笔批注）与**印章**：

  > "李华"是每一位中国学生在英语作文里写过的那个名字——整个方向就是**一篇被红笔批改过的文章**：朱色的印章标识、朱色的批注式下划线、朱色的阅读进度条。

### 1.2 核心色板（6 个命名值）

| 名称             | Hex       | 用途                                     |
| ---------------- | --------- | ---------------------------------------- |
| **纸 paper**     | `#F6F6F4` | 浅色 base-100（冷白纸，非米黄）          |
| **墨 ink**       | `#23262B` | 浅色正文/标题（base-content），非纯黑    |
| **朱 vermilion** | `#C9402F` | 品牌主色：primary 背景、印章、进度条     |
| **朱·文**        | `#B93A2B` | 浅色主题下的文字级朱色（链接、正文强调） |
| **纸·阴**        | `#ECECE9` | 浅色 base-200：分层、边框                |
| **墨·夜**        | `#17181A` | 深色 base-100（墨即纸）                  |

**设计约束**：
**品牌强色只有一个色相（朱）**——印章、链接、焦点、进度条、批注母题。其余一切都是墨与纸的明度层级。
例外仅一种：靛（`#3E5F84`/`#8FB4DC`）作为**语义系统色**（`secondary`/`info`）存在，只允许出现在系统级信息（如搜索结果计数、提示图标），**不得**用于品牌装饰、标题或主操作。`primary` 背景每页最多出现一次（页面最重要的那个动作），其余动作用中性/描边样式。

### 1.3 反模板自检

对照 AI 生成设计的常见默认逐一检查：

| 常见默认                           | 本规范的处理                                                                           |
| ---------------------------------- | -------------------------------------------------------------------------------------- |
| 暖米色底 + 高对比衬线 + 陶土色强调 | ❌ 冷白纸 `#F6F6F4` + 朱红 `#C9402F`（红而非陶土橙）；最近邻风险，靠色温与朱批母题区分 |
| 统一圆角卡片网格 + 柔和投影        | ❌ 首页默认视图是**索引行**（日期列 + 标题），非卡片网格；`--depth: 0`，全站无投影     |
| 全大写 eyebrow 标签                | ❌ 禁止；元信息用正常大小写的 14px 弱化文字                                            |
| 每个 section 淡入上移动画          | ❌ 默认**无入场动画**；动效规则见 §7                                                   |
| 标题中单词单独变色/加粗强调        | ❌ 禁止；强调靠朱色批注式下划线（母题），不用单词染色                                  |
| `→` 追加在链接文字后               | ❌ 禁止                                                                                |

**唯一刻意的冒险**：朱印标识（§6.1）——全站最大胆的元素，其余全部让路。

### 1.4 设计原则

1. **洁简**：结构靠排版与留白，不靠边框、卡片、阴影、装饰——全站投影为零、品牌强色只有一个色相（朱）；层级由字号阶梯与间距产生（原"排版即结构"并入本条）。
2. **实用**：每个交互必须解决真实阅读问题，不为炫技加功能。基准要求：文章目录可收起、目录按钮可拖动、全断点响应式（§9）。
3. **护眼**：不出现纯白/纯黑直对、默认跟随系统主题、禁止闪烁（§8）；字号 ≥16px、行高 1.75、行长 ≤42rem 为长文底线。
4. **朱不过二**：朱色只出现在三个地方——身份（印章）、交互（链接/焦点/进度条）、批注母题（下划线/圈点）。装饰性用色一律拒绝。
5. **双语同权**：中英混排按 §3.2 的度量规则处理，不把 CJK 当作拉丁的附庸。
6. **静**：动效只响应用户动作，或作为全页唯一的编排时刻；`prefers-reduced-motion` 全量尊重。

## 2. 色彩系统

> **与实现对接（ADR 0005 机制）**：原始色值在 `src/styles/theme-tokens.css` 以 `--palette-*` 定义，`src/styles/global.css` 的 `@plugin "daisyui/theme"` 把 `--color-*` 映射到对应 `--palette-*`，`data-theme` 切换时整表翻转。
> 本章表格列出的是 **daisyUI 语义层 `--color-*` 的目标值**（组件只应使用语义类名）；实现时必须同步补齐 `--palette-*` 原始值。
> `--color-ink-muted` 是本规范的扩展语义变量，需在 `@theme` 中声明才能生成 `text-ink-muted` 等工具类。

### 2.6 对比度要求（已按 WCAG 2.1 相对亮度核算，验收时复测）

| 组合（前景 / 背景）               | 对比度  | 要求     |
| --------------------------------- | ------- | -------- |
| 墨 `#23262B` / 纸 `#F6F6F4`       | ≈14.0:1 | ≥4.5:1 ✓ |
| 次要 `#646971` / 纸               | ≈5.1:1  | ≥4.5:1 ✓ |
| 朱·文 `#B93A2B` / 纸              | ≈5.2:1  | ≥4.5:1 ✓ |
| 朱·文 `#B93A2B` / 纸·阴 `#ECECE9` | ≈4.8:1  | ≥4.5:1 ✓ |
| 靛 `#3E5F84` / 纸                 | ≈6.1:1  | ≥4.5:1 ✓ |
| 白 / 朱 `#C9402F`                 | ≈4.9:1  | ≥4.5:1 ✓ |
| 纸白 `#E8E7E2` / 墨夜 `#17181A`   | ≈14.3:1 | ≥4.5:1 ✓ |
| 亮朱 `#FF7A66` / 墨夜             | ≈7.0:1  | ≥4.5:1 ✓ |
| 深色次要 `#9BA0A7` / 墨夜         | ≈6.8:1  | ≥4.5:1 ✓ |

- 计算方式：WCAG 2.1 相对亮度公式，结果四舍五入到 0.1；最终以重写后 `axe` / Lighthouse 实测为准。
- 正文与元信息 ≥4.5:1；大字（≥24px 或 ≥18.66px 粗体）≥3:1。
- **规则**：只用 daisyUI 语义色名（`text-primary`、`bg-base-100`…），不裸写 Tailwind 色名做文字色；不使用 `dark:` 覆盖语义色（由主题变量自动切换）。

| 语义 token  | 浅色主题                         | 深色主题  |
| ----------- | -------------------------------- | --------- |
| 注释        | `#646971`（ink-muted，斜体禁用） | `#9BA0A7` |
| 关键字      | `#B93A2B`（朱·文，唯一彩色）     | `#FF7A66` |

| 数字/常量   | `#3E5F84`（靛）                  | `#8FB4DC` |

## 3. 字体排印

### 3.1 字体族与角色

| 角色      | 字体栈                                                                                            | 说明                                                               |
| --------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| 标题/展示 | `"Source Serif 4", "Source Han Serif SC", "Noto Serif SC", "Songti SC", "SimSun", serif`          | Latin 自托管 woff2 子集；中文依赖本地宋体族（不加载 CJK 网络字体） |
| 正文/UI   | `system-ui, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif` | 长文可读性优先，中英同栈                                           |
| 代码      | `ui-monospace, "SF Mono", "JetBrains Mono", "Cascadia Mono", Consolas, monospace`                 | 代码块、行内码、日期数字                                           |

- **Source Serif 4** 与 Source Han Serif（思源宋体）同为 Adobe 设计的配套家族，中英标题并置时骨架呼应——这是选它的理由，不是随手默认。
- 预算：Latin woff2 子集 ≤ 60KB，`font-display: swap`，仅预加载文章页 h1 所需字重（700）。
- 中文**不加载网络字体**（CJK 字库体积违反 BundleSizeBudget），靠系统宋体栈；若未来必须统一，先走依赖评估再议。
- 落点：字体文件置于 `public/fonts/` ⏸，`@font-face` 定义在 `src/styles/theme-tokens.css`；用 `size-adjust`/`ascent-override` 对齐回退字体度量，抑制 CLS。
- 字体只是增强：任何自定义字体加载失败时，回退栈必须保持版式可用（不改变字号阶梯与行长）。

### 3.2 字阶（16px 基准，1.25 模数）

| 角色      | 尺寸 | 行高     | 字重 | 用途                        |
| --------- | ---- | -------- | ---- | --------------------------- |
| caption   | 13px | 1.5      | 400  | 图注、辅助说明              |
| meta      | 14px | 1.5      | 400  | 日期、标签、阅读时长        |
| body      | 16px | **1.75** | 400  | 正文（CJK 需要更大行高）    |
| lead / h4 | 20px | 1.6      | 400  | 摘要、导语                  |
| h3        | 25px | 1.35     | 600  |                             |
| h2        | 31px | 1.3      | 600  | 页面 h1（列表页）           |
| h1        | 39px | 1.25     | 700  | 文章标题（移动端降为 31px） |

- **对齐**：全部左对齐；**禁止两端对齐**；仅空状态与页脚短句居中。
- **行长**：正文列 `max-width: 42rem`（≈70+ 拉丁字符 / ≈36 个 CJK 字符）。
- **数字**：日期与阅读时长用 `font-variant-numeric: tabular-nums`。
- **字距**：仅 h1/h2 的拉丁字符 `letter-spacing: -0.01em`；CJK 与正文保持 `0`。
- **折行**：标题 `text-wrap: balance`、正文 `text-wrap: pretty`（渐进增强，不支持时自然折行）。
- **中英混排**：CJK 与拉丁/数字之间的空隙交给字体度量与 `text-autospace`，**不手动插入空格**；标点按所属语言（中文全角、英文半角）。
- **模数例外**：`meta 14px` 为接近 UI 惯例的离阶值，刻意不纳入 1.25 模数；除此之外不得新增离阶字号。
- **禁止**：全大写标签、标题单词单独染色/斜体强调、内容上方的装饰性 eyebrow 标签。
- **权威来源**：中英混排与双语的完整策略见 `docs/I18N.md`；本节只约束与视觉度量（字号/行高/行长/间距）相关的部分。

### 3.3 朱批母题（唯一的排版装饰）

- 强调：`border-bottom: 2px solid` 朱色（`--color-accent`），即红笔划线；不用 `font-weight` 单词强调。
- 引用（blockquote）：左侧 3px 朱色竖线 + 常规正文，不整块染色。
- 圈点：仅用于文章内"结论/要点"标记，每篇 ≤ 3 处。

## 4. 间距与形状

- **4px 网格**：所有 margin/padding 取 4 的倍数；常用步进 4/8/12/16/24/32/48/64/96。
- **区块节奏**：页面主区块间距 64px（移动端 48px）；文章内 h2 上方 48px、下方 16px。
- **圆角**（daisyUI 变量，按语义分三档，禁止全站套用同一值）：
  - `--radius-selector: 0.25rem`（标签、开关等小型选择器）
  - `--radius-field: 0.25rem`（输入框、按钮）
  - `--radius-box: 0.5rem`（卡片、代码块、面板）
  - 特例：朱印标识 12px（§6.1）、目录浮动按钮为正圆（§9.3）。
- **尺寸**（daisyUI 变量）：`--size-selector: 0.25rem`、`--size-field: 0.25rem`（daisyUI 5 必填，决定按钮/输入框高度步进）。
- **边框**：`--border: 1px`，色取 `--color-base-300`；**全站无投影**（`--depth: 0`、`--noise: 0`）。
- **焦点**：`focus-visible` 统一 2px 朱色轮廓 + 2px 偏移（`outline-offset: 2px`）。
- **层级 (z-index)**：只允许下列层级，禁止就地魔数，避免弹层互相遮挡。

  | 层           | z-index | 元素                    |
  | ------------ | ------- | ----------------------- |
  | 正文/页面    | `0`     | 普通内容                |
  | 顶部导航     | `40`    | Navbar（sticky）        |
  | 阅读进度条   | `50`    | 贴顶进度条              |
  | 浮动目录按钮 | `60`    | 可拖动按钮（§9.3）      |
  | 目录面板     | `70`    | TOC 浮层/抽屉           |
  | 搜索面板     | `80`    | PagefindSearch 结果面板 |
  | Toast        | `90`    | 全局轻提示（§6.2）      |

## 8. 护眼 (Eye Comfort)

- **无眩光基底**：浅色底 `#F6F6F4`（非纯白 `#FFF`）、深色底 `#17181A`（非纯黑 `#000`）；文字 `#23262B` / `#E8E7E2`，避免纯黑纯白直对造成的光晕疲劳。
- **对比度上限**：正文对比度控制在 4.5:1–15:1（§2.6），不追求"越对比越清晰"。
- **默认跟随系统**：主题初始值取 `prefers-color-scheme`，用户手动切换后记忆；无 FOUC（BaseLayout 内联主题脚本）。
- **闪烁禁止**：任何元素闪烁频率 ≤3Hz——全站无闪烁元素；禁止自动播放的循环动画；代码高亮不用霓虹高饱和色。
- **选区与反馈**：`::selection` 用 `primary/15` 淡朱底（非高饱和整块）；hover 过渡 120–160ms，无频闪。
- **长文兜底**：字号 ≥16px、行高 1.75、行长 ≤42rem、段间距 ≥1em（§3.2/§4）。
- **大面积朱色禁止**：朱仅点缀（占页面面积 ≤5%），无整屏朱色 banner。
- **滚动条**：宽度 ≤12px、`base-300` 低对比，随双主题同步。
- **深色衬底**：深色主题下代码块/图片容器用 `base-200`（`#1F2124`）而非纯黑衬底，降低明暗跳变。
- **高对比偏好**：`prefers-contrast: more` 时加深次要文字（`--color-ink-muted` 向 `base-content` 靠拢）、边框提到 `base-content/30`；不改变色相。
- **系统深色**：`prefers-color-scheme` 仅决定初始主题，用户显式选择后不再被系统覆盖（§10）。

### 8.1 打印样式

长文需可打印存档，打印稿是"纸墨"母题的自然延伸：

- **去壳**：隐藏 Navbar、目录侧栏/浮动按钮、进度条、分页、Toast、复制按钮；正文单列全宽。
- **颜色**：强制纸白底 + 墨色文字（`@media print { color-scheme: light }`），朱色只保留链接下划线与印章；移除 `primary` 填充。
- **展开链接**：正文链接在括号内补出 URL（`a[href^="http"]::after { content: " (" attr(href) ")" }`），站内锚点除外。
- **分页**：`h2/h3` 前 `break-after: avoid`、图/表/代码块 `break-inside: avoid`；`@page { margin: 20mm }`。
- **页脚**：打印稿末尾追加来源 URL 与生成日期（`content: attr(...)` 或打印专用元素）。

## 9. 实用交互规范：文章目录 (TOC)

本节是 ClientModule `toc` ⏸（`src/scripts/toc.ts`，`pageLoad`/`afterSwap` 生命周期）的**行为规格**，属硬性验收项（原则 2"实用"的基准要求）。

### 9.1 响应式形态

| 断点 / 状态        | 形态                                                  |
| ------------------ | ----------------------------------------------------- |
| ≥1024 (lg)         | 右侧 sticky 侧栏（16rem），默认展开，可整栏收起       |
| <1024 或侧栏已收起 | 显示浮动目录按钮（默认右下 48px），点按开合面板       |
| 768–1023 (md)      | 面板为距按钮 12px 的浮层，`max-height: 60vh` 内部滚动 |
| <768 (sm)          | 面板为底部抽屉，`max-height: 60vh` 内部滚动           |

- 侧栏与浮动按钮**互斥**出现：侧栏存在时不显示按钮，收起后按钮出现。
- 跨断点 resize：面板自动关闭，按钮位置重新 clamp 到视口内。

### 9.2 收起（两级）

1. **整栏收起**：侧栏头部 `«` 按钮（触达区 ≥44×44px）→ 侧栏收起、浮动按钮出现；状态存 `localStorage["toc:collapsed"]`，**跨页记忆**。
2. **多级折叠**：目录树按 h2/h3 分层，子级 `▸/▾` 逐级折叠；深层子级默认只展开**当前阅读小节**所在分支，其余折叠。折叠状态仅本次会话有效（不跨页，避免下次打开"目录不见了"）。
3. 收起/展开不改变正文列宽以外的布局（无横向跳动）。

### 9.3 拖动目录按钮

- **Pointer Events** 统一鼠标/触摸/笔；`touch-action: none` **仅施加于按钮**，页面其余区域正常滚动。
- **手势判定**：位移 >6px 判为拖动，否则判为点按（开/关面板）；拖动跟手、无惯性。
- **吸附与边界**：释放后水平方向吸附最近边缘（边距 12px），垂直位置保留；任何时刻不越出视口，不覆盖顶栏操作区与进度条热区。
- **位置记忆**：以 viewport 高度归一化（0–1）存 `localStorage["toc:btnPos"]`，加载与 resize 后重新 clamp；**双击按钮恢复默认位置**。
- **样式**：48px 圆形；静止态 `bg-base-100`

* 1px `base-300` 边框 + 墨色 ≡ 图标（安静）；打开态转 `bg-primary`。z-index 低于搜索面板/模态，高于正文。

- **键盘与读屏**：按钮 `aria-expanded`/`aria-controls`；Enter/Space 开关，Esc 关闭且焦点回到按钮，面板内方向键遍历目录项；拖动不破坏键盘操作路径。

### 9.4 高亮与滚动

- IntersectionObserver 标记当前小节：左侧 2px 朱线 + 朱文字（accent）；随滚动移动（功能性，允许）。
- 点击目录项：平滑滚动定位 + 更新 URL hash；`prefers-reduced-motion` 下瞬时定位；移动端点按后面板自动关闭。
- 面板开合过渡 ≤160ms（用户动作驱动，符合 §7）；reduced-motion 下瞬时。

### 9.5 其他实用交互（同级要求）

- **标题锚点**：hover/focus 于 h2/h3 显示 `¶`，点按复制该节链接（toast「已复制」）。
- **搜索快捷键**：`/` 或 `Ctrl/Cmd+K` 聚焦 PagefindSearch（聚焦输入框，不做全屏花哨弹层）。
- **代码复制**：CodeCopy 模块既有行为保留，成功反馈复用同一 toast。

## 10. 可访问性底线

> 本节只列**与视觉/交互直接相关**的硬性底线；完整无障碍基线（语义、键盘、屏幕阅读器、测试方法）以 `docs/ACCESSIBILITY.md` 为准。

- 正文对比度 ≥4.5:1（§2.6 已核算，实现后复测）；大字 ≥3:1。
- 键盘：所有交互可达，`focus-visible` 朱色 2px 轮廓全局可见；提供"跳到正文"跳转链接。
- 触达：可点击区域 ≥44×44px（含标签、图标按钮）。
- 语义：一页一个 `h1`；标题层级不跳级；地标元素（`header/main/footer/nav`）齐全。
- 缩放：200% 缩放不产生横向滚动（正文列与代码块的横向滚动除外）。
- 主题切换：`color-scheme` 同步，浏览器 UI（滚动条、表单控件）跟随双主题；无 FOUC（BaseLayout 内联主题脚本 ⏸）。
- 偏好：尊重 `prefers-reduced-motion`（§7）、`prefers-contrast`（§8）与 `prefers-color-scheme`（§8）；用户显式选择优先于系统偏好。
