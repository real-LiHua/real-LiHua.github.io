## 1. 对比度

正文对比度 ≥4.5:1，大字（≥18.66px 粗体 或 ≥24px）≥3:1。已核算取值见 `docs/VISUAL_DESIGN_SPEC.md` §2.6：

| 组合                            | 对比度  | 要求     |
| ------------------------------- | ------- | -------- |
| 墨 `#23262B` / 纸 `#F6F6F4`     | ≈14.0:1 | ≥4.5:1 ✓ |
| 次要 `#646971` / 纸             | ≈5.1:1  | ≥4.5:1 ✓ |
| 朱·文 `#B93A2B` / 纸            | ≈5.3:1  | ≥4.5:1 ✓ |
| 白 / 朱 `#C9402F`               | ≈4.9:1  | ≥4.5:1 ✓ |
| 纸白 `#E8E7E2` / 墨夜 `#17181A` | ≈14.8:1 | ≥4.5:1 ✓ |
| `#FF7A66` / 墨夜                | ≈7.1:1  | ≥4.5:1 ✓ |
| 深色次要 `#9BA0A7` / 墨夜       | ≈6.9:1  | ≥4.5:1 ✓ |

**规则**：

- 只用 daisyUI **语义色名**（`text-primary`、`bg-base-100`…）做文字色，不裸写 Tailwind 色名。
- 不使用 `dark:` 覆盖语义色——由主题变量自动切换。
- 对比度上限约 15:1（护眼，避免纯黑纯白直对）。

> 以上为设计核算值；**实现后必须用工具复测**（见 §11）。

## 2. 键盘可访问性

| 要求         | 说明                                                                                                |
| ------------ | --------------------------------------------------------------------------------------------------- |
| 全部交互可达 | 所有链接、按钮、表单、目录、搜索均可用键盘操作                                                      |
| 跳转链接     | 提供"跳到正文"skip link，位于 DOM 首部、聚焦时可见                                                  |
| 焦点可见     | 全局 `focus-visible` 轮廓（见 §3）                                                                  |
| 无键盘陷阱   | 除模态外不得困住焦点；模态/浮层 Esc 关闭并可返回                                                    |
| 目录键盘行为 | `aria-expanded` / `aria-controls`；Enter/Space 开关；Esc 关闭且焦点回按钮；方向键遍历目录项（§9.3） |
| 搜索结果     | 结果可 Tab 遍历；项目可 Enter 进入                                                                  |
| 折叠/展开    | 折叠面板按钮暴露 `aria-expanded`                                                                    |

**搜索快捷键**：`/` 或 `Ctrl/Cmd+K` 聚焦搜索输入框（仅聚焦，不做全屏弹层，§9.5）。快捷键不应拦截输入框内正常打字。

## 3. Focus 可见 (focus-visible)

- 统一 **2px 朱色轮廓**（`--color-accent`）+ `outline-offset: 2px`。
- 作用于所有可聚焦元素；不得用 `outline: none` 而无替代。
- 与 hover 态区分：焦点态必须显式可见，不能仅靠颜色变化。

```css
:focus-visible {
  outline: 2px solid var(--color-accent);
  outline-offset: 2px;
}
```

---

## 4. 触达目标 (Touch Targets)

- 可点击区域 **≥44×44px**（含标签、图标按钮、目录按钮）。
- 目录整栏收起按钮触达区 ≥44×44px（§9.2）。
- 浮动目录按钮 48px 圆形（§9.3）。
- 相邻目标之间保留足够间距，避免误触。
- 鼠标/触摸/笔统一用 Pointer Events（目录拖动，`touch-action: none` 仅施加于按钮）。

---

## 5. 语义与地标 (Landmarks & Headings)

| 要求        | 说明                                                   |
| ----------- | ------------------------------------------------------ |
| 一页一个 h1 | 每页仅一个 `<h1>`；文章标题即 h1                       |
| 标题不跳级  | h1 → h2 → h3，不出现 h1 → h3                           |
| 地标完整    | `<header>` / `<main>` / `<footer>` / `<nav>` 各司其职  |
| 导航        | 主导航用 `<nav>` 并带可访问名称（`aria-label`）        |
| 目录        | `<nav aria-label="文章目录">`；当前节用 `aria-current` |
| 语言        | `<html lang>` 与实际主语言一致（见 `docs/I18N.md` §1） |
| 认证墙      | 按钮/说明语义化；步骤列表用有序列表                    |

## 6. 缩放 (Zoom & Reflow)

- **200% 缩放不产生横向滚动**（正文列与代码块自身的横向滚动除外）。
- 不使用固定像素宽度锁死布局；正文列用 `max-width: 42rem` 自适应。
- 文字可放大到 200% 而不丢失内容或功能。

---

## 7. 动效与 reduced-motion

- 全量尊重 `prefers-reduced-motion`：非功能性动效归零。
- 阅读进度条保留，但 reduced-motion 下**瞬时跳变**（不做平滑动画）。
- 目录面板开合、锚点滚动在 reduced-motion 下瞬时完成。
- 禁止闪烁（≤3Hz，实际全站无闪烁元素）与自动循环动画（`docs/VISUAL_DESIGN_SPEC.md` §7/§8）。
- `tilt-card`（若保留）在 reduced-motion 与触屏下禁用。

---

## 8. 主题与视觉稳定性

- 主题初始值跟随 `prefers-color-scheme`，用户切换后记忆。
- 无 FOUC：主题脚本内联于 `BaseLayout` ⏸。
- `color-scheme` 同步，浏览器 UI（滚动条、表单控件）随双主题。
- 选区 `::selection` 用淡朱 `primary/15`，非高饱和整块。

---

## 9. 图片与媒体

- 每张信息图提供 alt 文本；装饰图 `alt=""`。
- 图注（caption）用 13px 弱化文字（视觉对比仍达标）。
- Mermaid 渲染为 SVG 时，复杂图应有等价文字说明。
- 代码块提供复制按钮，且有成功反馈（toast，屏幕阅读器可感知）。

---

## 10. 表单与搜索

- 输入控件有关联 `<label>` 或 `aria-label`。
- 错误/状态信息用可感知方式通告（`aria-live`）。
- Pagefind 输入框在暗色主题下映射 `--pagefind-ui-*` 变量（见 `docs/SEARCH_TUNING.md`），保证对比度。
- 搜索面板 z-index 与焦点管理正确，Esc 关闭。
