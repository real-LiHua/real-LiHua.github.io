## 任务描述

为 post-edit CLI 工具补全集成测试，覆盖 CRUD 操作、搜索、草稿流转等核心流程。

## 输入

- **文件**: `src/post-edit/main.rs` (现有单元测试在第 527-628 行)
- **测试目标**:
  - `get_all_posts` - 读取 posts/ 和 posts/drafts/ 目录
  - `get_post_info` - 解析 frontmatter、判断草稿状态
  - `search_posts` - 关键词搜索标题/标签/描述
  - `create_new_post` - 创建文件、生成 frontmatter
  - `toggle_draft` - 发布/设为草稿（文件移动）
  - `delete_post` - 删除文件
  - `edit_post` - 调用外部编辑器

## 期望输出

- **文件**: `src/post-edit/tests/integration.rs` 或 `main.rs` 内 `#[cfg(test)] mod integration_tests`
- **测试**: 覆盖率 > 80%，`cargo test` 全绿

## 验收标准

```bash
cargo test
# 所有集成测试通过
# 覆盖率 cargo tarpaulin 或 cargo llvm-cov > 80%
```

## 实现提示

- 使用 `tempfile` 创建临时目录隔离测试环境
- 模拟 stdin/stdout 测试交互菜单（或重构为可测试函数）
- 测试文件移动逻辑：posts/ ↔ posts/drafts/
- 测试 frontmatter 解析边缘情况（缺失字段、空值、格式错误）
- 考虑提取核心逻辑为纯函数便于单元测试
