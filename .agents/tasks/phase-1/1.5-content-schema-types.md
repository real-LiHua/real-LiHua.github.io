## 任务描述

`src/content.config.ts` 定义的 Zod schema 仅用于内容加载验证，前端组件无法直接复用类型。导出推导类型供 Astro 组件使用。

## 输入

- **文件**: `src/content.config.ts` (blog collection schema)
- **现有类型**: `title`、`authors?`、`description?`、`image?`、`publishDate?`、`updatedDate?`、`tags?`

## 期望输出

- **导出**: `BlogPostData`、`BlogPost` 类型（含 `id`、`slug`、`data`、`body`）
- **用法**: 前端可 `import type { BlogPost } from 'astro:content'` 或从共享模块导入

## 验收标准

```bash
pnpm tsc -b       # ✓ 0 errors
# 前端组件可使用：
# import type { BlogPost } from '@/utils/content-types';
# const post: BlogPost = ... // 类型完整
```

## 实现提示

```typescript
// src/content.config.ts 末尾追加导出
import type { InferEntryType } from "astro:content";

export type BlogPostData = InferEntryType<"blog">["data"];
export type BlogPost = InferEntryType<"blog">;

// 或创建 src/utils/content-types.ts 统一导出
```

- 使用 `InferEntryType` 自动推导，避免手动维护
- 确保 `data` 字段包含所有 frontmatter 字段
- `body` 类型为 `string` (原始 markdown)
- 供 `src/utils/content.ts` 的 `getPublishedPosts` 等函数返回类型使用
