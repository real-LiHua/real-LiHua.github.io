## 任务描述

目前各页面/组件分别 `<script>` 导入所需脚本，存在重复加载、初始化时机不一致问题。建立统一注册表，在 `BaseLayout` 中按需加载。

## 输入

- **文件**:
  - `src/layouts/BaseLayout.astro` (当前内联加载 theme-toggle、Pagefind)
  - `src/scripts/*.ts` (8 个脚本)
  - 各页面组件内部的 script 导入
- **现状**: 每个脚本独立监听 `astro:page-load`，重复初始化

## 期望输出

- **新增**: `src/scripts/registry.ts` - 脚本注册表（名称、依赖、初始化函数）
- **修改**: `BaseLayout.astro` - 统一加载注册表、按页面特性启用
- **清理**: 页面组件内移除重复 script 导入

## 验收标准

```bash
pnpm dev          # ✓ 启动无误
pnpm build        # ✓ success
# 手动验证：主题切换、TOC、代码复制、阅读进度、搜索均正常
# 无重复初始化日志、无 "already initialized" 警告
```

## 实现提示

```typescript
// src/scripts/registry.ts 示例结构
export const scriptRegistry = {
  "theme-toggle": { init: () => import("./theme-toggle.ts"), deps: [] },
  toc: { init: () => import("./toc.ts"), deps: ["theme-toggle"] },
  "code-copy": { init: () => import("./code-copy.ts"), deps: [] },
  // ...
};

// BaseLayout 中根据页面特性（如是否有文章内容）决定加载哪些脚本
```

- 保持 `astro:page-load` 事件驱动模式
- 支持动态 import（代码分割）
- 兼容 `astro:after-swap` (ClientRouter 导航后)
